# 커뮤니티 조사와 음색 설계

2026-10-29 조사. 28개 출처 기록(커뮤니티 22, 제작자/제조사/튜토리얼 6), 교차게시 가능성을 묶으면 27개 그룹이다. 페이지 내용을 확인한 10개와 검색 발췌만 확인한 18개를 구분했다. **대규모 통계 표본이나 확정된 세션 장비 목록이 아니다.** 원문·타사 패치·곡 음원은 재배포하지 않는다.

| 관찰 | 출처 | 구현 |
|---|---|---|
| 벨 어택 위에 부드러운 지속음 | C01, C19, P02, P05 | 3개의 2-operator pair, 몸통/틴 envelope 분리 |
| 타건에 따른 밝기 변화 | C04, C05, C07, P01, P02 | carrier KVS2/3, modulator KVS4/5/6 |
| 높은 ratio 틴과 낮은 ratio 몸통 | C08, C11, C14, P02 | body1, tine10/12/14 |
| chorus/detune/레이어의 중요성 | C05, C09, P01, P03 | 약한 detune, preset별 FX와 SPREAD |
| DX/TX, MKS, rompler 추정 충돌 | C02, C03, C06, C10, C13, C16 | 특정 Babyface 패치 복원 주장 금지 |

초기 개발에서는 704개 최종 grid와 36후보×40조건 탐색을 두 번 수행했다. 낮은 틴 레벨(54–72), 빠른 감쇠(rate62–82)는 벨 성분이 너무 빨리 사라졌다. 그래서 틴 레벨78–96, rate24/36/48, ratio10/12/14로 탐색을 옮겼다. DX rate는 작을수록 느리다. 메인 프리셋은 90/12/36에서 출발했고, 강한 벨 후보96/14/24는 Bell Touch에 배치했다.

초기/후기 spectral centroid 비율 1.8을 선호했던 탐색 점수는 개발자 휴리스틱이며 **녹음 유사도나 커뮤니티 실측값이 아니다**. 전체 기존 작업에서 4,288개 합성 렌더 조건을 계산했으나, 작업 환경 자동 정리로 당시 sweep CSV는 소실되었다. 따라서 이 저장소는 그 원시 데이터를 보유한다고 주장하지 않는다. 복구 후 새로 실행한 **최종 704조건 CSV**와 16개 데모 검증 결과만 배포한다.

정확한 싱크를 위해 남은 일: 기준곡3–5개와 구간 선정 → 적법하게 이용할 수 있는 레퍼런스를 로컬에서 비교 → 음량 정렬 → 어택/몸통/타건/공간감 각각 블라인드 평가 → 실기 line-out/velocity 측정. 완성 음반의 보컬·드럼 혼합 스펙트럼을 EP 단독 목표로 삼지 않는다. 수백/수천 게시물 수준의 연구는 사이트가 허용하는 접근 방법, 중복 제거, 표본 기간/제외 기준을 갖춰 별도로 확장해야 한다.

검색축: Babyface ballad EP, 90s R&B FM Rhodes, DX phased Rhodes, Full Tines, MKS20 R&B, DX7 velocity chorus, Digitone R&B, EP programming. RME Babyface 인터페이스, 판매만 하는 페이지, 출처 없는 요약글은 주요 근거에서 제외했다. C02/C03은 같은 그룹, C13은 홍보 편향이 있다. Arturia의 모든 operator 레벨을 최대로 올리라는 조언은 그대로 적용하지 않았다.
