# Velvet EP 90

SMK-37 Pro용 오리지널 R&B FM EP 프로젝트. [8개 프리셋 × velocity 64/112 데모](dist/demos/)를 먼저 공개합니다. 실제 펌웨어 C DSP에서 렌더링한 자체 코드 진행이며 하드웨어 녹음이 아닙니다.

작업 환경 자동 정리로 소스/빌드 파일 복구 중입니다. 펌웨어 배포 완료 전까지 설치용 파일은 제공하지 않습니다. 실기 미검증 alpha이며 특정 곡과의 유사도는 검증하지 않았습니다.

Demo performances: GPL-3.0-only. No commercial recording samples used.
